Your scripted tests cover known journeys. CheckQuest explores an authorized website for potential problems you didn’t write a test for, investigates within explicit limits, and brings back evidence.

How a run works

From first pass to final report.

01

Explore

Inspect the start page, then spend the remaining page budget on useful, different internal routes.

02

Investigate

Take only narrow, approved actions that can gather evidence for a specific potential issue.

03

Report

Group related observations, keep their evidence together, and show what is verified and what still needs human review.

Make room for discovery

An autonomous exploratory QA pass.

Start from a URL rather than a test script. Gemini helps suggest what looks worth investigating; deterministic policy controls eligible routes, actions, and budgets.

Coverage and model output vary. A run is a bounded sample, never proof that a site is defect-free.

Safety by design

Autonomous, not unbounded.

You set the scope. Deterministic policy constrains the browser, even when a model suggests the next step.

01

Bound the run

Separate page, navigation, and per-page investigation budgets bound the work.

Page budgetsBounded navigation
02

Constrain interaction

Autonomous actions stay narrow, candidate-linked, and purpose-specific.

Guarded actionsNo arbitrary clicksNo submit actions
03

Back off on password pages

Visible password fields suppress investigation. An unsafe interaction state can stop the run.

Password-page backoffRollback
04

Keep security passive

Observe useful security posture without turning the run into vulnerability probing.

Authorized sites onlyNo active probing

Safety controls reduce risk; they cannot guarantee zero side effects. Page loads and supported interactions can still trigger website behavior. Inspect only sites you are authorized to test.

Take it for a small expedition

Start with the CLI.

You’ll need Git, Node.js 22.13.0+, npm 10+, Chromium setup, and your own Gemini API key. Model requests may incur provider charges.

CLI · available from source

Start with one page.

Follow the installation guide, set your key, then try a small run with investigation disabled. 

npm start -- https://your-site.example/ --pages 1 --navigation-steps 1 --steps-per-page 0

Replace the URL with an authorized target. Page analysis still uses Gemini.
